## 🌟 Task 4: Music Player (AuraBeats) Highlights

- **Aesthetic:** Modern streaming UI with obsidian dark glassmorphism, glowing accents, and animated ambient gradient backdrops.
- **Audio Engine:** HTML5 Audio API with Play, Pause, Next, Previous, Shuffle, and 3-mode Repeat (Off / All / One).
- **Interactive Vinyl:** Spinning album cover and physical vinyl disc slide-out effect synchronized with playback state.
- **Equalizer Visualizer:** Real-time animated canvas soundwave bars with harmonic motion.
- **Playlist & Search:** 5 full NCS royalty-free tracks with high-res artwork, live keyword filtering, and Liked Songs tab persisted to `localStorage`.
- **Keyboard Shortcuts:** Full keyboard accessibility (Space to play/pause, arrows to seek/volume, M to mute, S for shuffle, R for repeat, L for like, ? for cheatsheet).

## 🌟 Task 1: Image Gallery Highlights

- **Aesthetic:** Dark / Light theme with obsidian glassmorphism and fluid typography.
- **Dynamic Filtering:** 5 rich categories (`Nature`, `Architecture`, `Travel`, `Animals`, `Technology`) with real-time count badges.
