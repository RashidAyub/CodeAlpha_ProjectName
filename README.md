## 🌟 Task 1: Image Gallery Highlights

- **Aesthetic:** Dark / Light theme with obsidian glassmorphism and fluid typography.
- **Dynamic Filtering:** 5 rich categories (`Nature`, `Architecture`, `Travel`, `Animals`, `Technology`) with real-time count badges.
- **Search System:** Real-time debounced keyword search with clear button.
- **Interactive Lightbox:** Next / Previous navigation, counter (`1 / 24`), zoom, and full-resolution view.
- **Keyboard Shortcuts:** `←`, `→` arrow navigation, `Esc` to close, `Z` to zoom, and `/` to search.
- **Responsive:** Mobile touch swipe gestures, hamburger drawer menu, and adaptive CSS Grid & Masonry layouts.
